# NAI 프롬프트 갤러리

방문자는 썸네일과 이름을 보고, 누르면 프롬프트를 복사할 수 있는 창이 떠요.
올리기·수정·삭제는 숨겨진 관리자 화면(`사이트주소/#admin`)에서 코드를 입력해야만 열려요.

## 처음 설정 (한 번만)

1. **저장소 만들기**: GitHub에서 새 저장소를 만들어요(Public).
2. **파일 올리기**: 이 폴더의 파일을 전부 저장소에 올려요. 숨김 파일 `.nojekyll`과 `images`, `thumbs` 폴더도 포함해야 해요.
3. **Pages 켜기**: 저장소 Settings → Pages → Source를 `Deploy from a branch`로, 브랜치를 `main` / `(root)`로 정해요.
   1~2분 뒤 `https://사용자명.github.io/저장소이름/`에 사이트가 열려요.
4. **토큰 만들기**: GitHub 오른쪽 위 프로필 → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
   - Repository access: **Only select repositories** → 이 저장소만 선택
   - Permissions → Repository permissions → **Contents: Read and write**
   - 만료일은 원하는 대로 정해요. 만료되면 아래 "토큰이 만료됐을 때"를 따라 하면 돼요.
5. **관리자 설정**: `사이트주소/#admin`으로 들어가면 "처음 설정" 화면이 떠요.
   사용자명, 저장소 이름, 토큰, 관리자 코드를 입력하면 끝이에요.

## 평소 사용

- `사이트주소/#admin` → 코드 입력 → **+ 올리기**
- 이미지는 끌어다 놓기, 눌러서 선택, **Ctrl+V 붙여넣기** 모두 돼요.
- 올리기 창에 고친 내용이 있으면 실수로 닫히지 않게 한 번 더 물어봐요.
- 복사 창에서 **수정 / 맨 앞으로 / 삭제**를 할 수 있어요. "맨 앞으로"는 갤러리 첫 자리로 옮겨요.
- 복사 창에 나올 버튼은 올릴 때 정해요. "+ 프롬프트 / + 캐릭터 / + 네거티브 / + 직접 입력"으로 버튼을 추가하고, 버튼 이름은 자유롭게 고칠 수 있어요. ↑로 순서를 바꾸고 ×로 빼요.
- "설명" 칸에 적은 글은 복사 창에 이름 아래 회색 글자로 보여요. https 주소는 자동으로 링크가 돼요.
- NAI에서 받은 PNG를 그대로 넣으면 프롬프트, 캐릭터, 네거티브 버튼이 내용과 함께 자동으로 채워져요.
- 이미지는 자동으로 줄여서 올라가요(원본 1216px, 썸네일은 위쪽 기준 정사각형 480px).
- 카테고리는 GDED, 캐릭터, 페르소나, 짤방, 1인, 2인, 의상으로 정해져 있고, 올릴 때 드롭다운에서 골라요. 카테고리를 추가·삭제하거나 순서를 바꾸려면 **설정 → 카테고리 순서**에서 한 줄에 하나씩 고치면 돼요. "없음"을 고르면 "기타" 탭에 들어가요.
- 저장하면 사이트에 반영되기까지 1~2분 걸려요. 관리자 화면에는 방금 올린 이미지가 바로 보여요.
- 한 번 저장할 때 이미지·썸네일·목록이 커밋 하나로 같이 올라가요. 중간에 실패해도 반쯤 올라간 상태가 남지 않아요.
- 프롬프트 창 주소(`#p-...`)를 그대로 보내면 그 프롬프트가 바로 열려요.
- 복사 창에서 ←/→ 키(모바일은 사진을 좌우로 밀기)로 같은 탭의 이전·다음 프롬프트로 넘어가요.
- 관리자 모드는 브라우저에 기억되지 않아요. 새로고침하면 다시 코드를 입력해야 해요.

## 알아 둘 점

- GitHub 토큰은 관리자 코드로 암호화해서 `admin.json`에 저장돼요. 코드를 모르면 주소를 알아도 올릴 수 없어요.
- 대신 `admin.json`은 공개 파일이라서 **코드는 길고 추측하기 어렵게** 정해 주세요(12자 이상 권장).
- **코드를 잊었을 때 / 토큰이 만료됐을 때**: 저장소에서 `admin.json`을 삭제한 뒤 `#admin`으로 들어가 처음 설정을 다시 하면 돼요. 올려 둔 프롬프트는 그대로 남아요.
- 데이터는 `prompts.json`, 이미지는 `images/`, `thumbs/` 폴더에 쌓여요.
